# Utilisation de l'IA dans le projet

## Domaines d'utilisation

### 1. Migrations de base de données

L'IA a été utilisée pour générer et optimiser les scripts de migration de la base de données.

**Raison :**
- **Gain de temps** : Génération rapide de scripts SQL complexes
- **Réduction d'erreurs** : Syntaxe SQL correcte et cohérente
- **Optimisation** : Suggestions de contraintes et d'index appropriés

---

### 2. Peuplement de la base de données

L'IA a assisté dans le peuplement des databases

**Raison :**
- **Gain de temps** : Génération rapide de jeux de données cohérents
- **Données réalistes** : Création de Pokémon avec des statistiques équilibrées
- **Volume** : Génération facile de grandes quantités de données pour les tests

---

### 3. JavaScript / Frontend

L'IA a été utilisée pour développer et améliorer le code JavaScript côté client.

**Raison :**
- **Meilleure qualité visuelle** : Code optimisé pour des animations et interfaces fluides
- **Gain de temps** : Génération rapide de fonctions interactives
- **Qualité du code** : Respect des bonnes pratiques JavaScript modernes
- **Compatibilité** : Code compatible avec différents navigateurs

---

Tout code généré par IA a été vérifié et testé
